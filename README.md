## 🌟 வணக்கம் (Welcome)

**Tamil Devs** is a collaborative, zero-gatekeeping community built for Tamil developers across India, Singapore, Malaysia, Sri Lanka, Europe, the US, and around the globe. 

Whether you are writing your first line of code, preparing for FAANG/product interviews, or architecting distributed systems, this community provides a supportive space to collaborate, review code, and grow your tech career.

---

## 💡 What Makes Tamil Devs Unique?

| Feature | Description |
| :--- | :--- |
| 📄 **Resume Review & Roast Forum** | Dedicated forum where members get constructive line-by-line feedback from senior engineers on resume bullet points and ATS formatting. |
| 👀 **Peer Code Reviews** | Submit your GitHub Pull Requests, architecture diagrams, or code snippets for friendly, high-standard peer reviews. |
| 🎙️ **Voice Co-Working & Mock Interviews** | Practice real technical DSA and System Design mock interviews, or code in silence in our 24/7 Co-Working voice rooms. |
| ✨ **Vibe Coding & AI Tools** | Dedicated hub for AI developer workflows: Cursor rules, Claude Code, Windsurf, Bolt.new, and autonomous agent patterns. |
| 💼 **Jobs, Contracts & Startups** | Verified job openings, internal referrals, US/EU remote freelance advice, and indie-hacker showcase. |
