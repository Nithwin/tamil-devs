# Contributing to Tamil Devs

Thank you for your interest in contributing to **Tamil Devs**! We are building the most comprehensive open-source repository of Tamil tech resources, roadmaps, and community projects.

---

## 📌 Ways to Contribute

1. **Add Curated Resources:**
   - Tamil Tech YouTube channels and tutorial playlists
   - Tamil blogs, podcasts, or free learning courses
   - Roadmaps and cheat sheets

2. **Add Tamil Open Source Projects:**
   - Libraries, tools, and apps built by Tamil developers
   - Repositories looking for contributors (Hacktoberfest, GSoC)

3. **Improve Documentation:**
   - Fix broken links, typos, or formatting

---

## 🚀 How to Submit a Pull Request

1. **Fork** this repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/tamil-devs.git
   ```
3. Create a new branch:
   ```bash
   git checkout -b add-resource-name
   ```
4. Add your resource in alphabetical order following the format:
   ```markdown
   * **[Project / Channel Name](URL)** — Concise 1-2 sentence description in English or Tamil.
   ```
5. Commit your changes with a clean message:
   ```bash
   git commit -m "docs: add [Resource Name] to curated list"
   ```
6. Push to your branch and open a **Pull Request**!
